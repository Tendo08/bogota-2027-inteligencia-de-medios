# Datos

| Archivo | Qué es |
|---|---|
| `corpus_carrillo_metadatos.csv` | Las 1.093 noticias con medio, título, fecha, enlace y clasificación. Sin el texto completo, por los derechos de los medios |
| `localidades_indicadores.json` | Indicadores de cada localidad: pobreza, tiempo de viaje al trabajo, etc. |
| `mapa_localidades.json` · `localidades_urbanas.geojson.json` | Formas de las localidades para dibujar los mapas |
| `delitos_por_localidad_scj.json` | Delitos por localidad, 2018-2026 (Secretaría de Seguridad) |
| `votos_alcaldia_2023_localidad.json` | Votos por localidad, Alcaldía 2023 |
| `votos_presidencia_2026_localidad.json` | Votos por localidad, Presidencia 2026 |
| `google_trends.json` | Búsquedas en Google sobre los precandidatos |
| `guion_escena_*.txt` | Guiones de dos escenas del video |
