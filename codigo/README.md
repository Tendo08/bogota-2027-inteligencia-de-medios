# Código

Todo el proyecto está hecho en **Python**.

- **`1_datos_y_scraping/`**: recolección de noticias y datos oficiales, limpieza, clasificación, gráficas y mapas.
- **`2_video/`**: animaciones de datos, montaje del video y sincronización de la voz.

Las claves de las APIs se leen de variables de entorno: aquí no hay ninguna.
