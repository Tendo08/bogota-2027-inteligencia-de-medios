# Datos y scraping

Los 20 scripts van numerados en el orden en que se corren.

| Scripts | Qué hacen |
|---|---|
| `01`-`03` | Descargan datos oficiales: DANE, encuestas y Registraduría |
| `04`-`05` | Cuentan los votos por localidad (Alcaldía 2023 y Presidencia 2026) |
| `06`-`07` | Descargan y preparan el mapa de las localidades |
| `08`-`09` | **Scraping:** buscan y bajan las noticias de 85 medios durante un año |
| `10` | Limpieza: quitan notas repetidas o que no tienen que ver |
| `11`-`12` | Clasifican cada nota: tema, encuadre, voz propia y localidad |
| `13` | Ordenan los datos de Google Trends |
| `14`-`18` | Hacen las gráficas y los mapas |
| `19`-`20` | Arman las láminas y exportan a Excel |
