# Video

Cómo se hizo el video ensayo con código.

| Archivo | Qué hace |
|---|---|
| `video_anim.py` | Dibuja las animaciones de datos: mapas, gráficas, autores y escenas |
| `video_montaje.py` | Une todo en orden: voz, animaciones, gameplay, música y efectos |
| `alinear_voz.py` | Sincroniza cada imagen con el momento en que la voz la nombra |
| `video_miniaturas.py` | Saca portadas de documentos y cuadros para usarlos en el video |
| `rehacer_escenas.py` | Vuelve a generar todas las animaciones después de un cambio |

La base visual se complementó con Google Flow (IA generativa) y edición propia.
